# 梦幻西游手游落地页（概念设计）

这是一个围绕《梦幻西游》手游制作的非官方互动落地页概念作品，展示三界世界观、三族主角、门派技能、召唤灵、伙伴社交与下载入口。

## 在线预览

[打开 GitHub Pages 在线网站](https://zhujy9413-commits.github.io/dream-westward-journey-mobile-landing-page/)

## 功能

- 约五秒剑侠客开场 CG：由远及近、剑意蓄势、横扫千军、破屏交接
- 开场支持 2.5 秒后跳过、一键静音、Escape 跳过与移动端适配
- 四张首屏 CG 轮播，支持按钮、圆点和滑动切换
- 首屏逐字标题、金色流光、景深聚焦与轻量视差动效
- 首屏背景与渐变蒙版使用同一变换层，视差移动时保持精准对齐
- 自适应星光／祥云氛围层，移动端自动降低粒子数量
- 四张独立首屏 CG，本地资源避免轮播缺图
- 世界观章节交互与四幅低干扰场景背景
- 人、仙、魔三族主角切换与角色大图展示
- 角色可选门派及门派图标
- 十四门派与代表技能筛选；每个门派拥有独立的宣传级场景与主题色
- 技能图标悬浮／键盘聚焦名称提示
- 按携带等级分类的召唤灵图鉴
- 伙伴与社交玩法展示
- iOS、Android 官方下载入口
- 桌面端与移动端响应式布局
- 自动尊重 `prefers-reduced-motion`，系统减弱动画时关闭动态效果

## 使用方式

项目是纯静态页面，无需安装依赖。直接打开 `index.html`，或使用任意静态文件服务器预览。
