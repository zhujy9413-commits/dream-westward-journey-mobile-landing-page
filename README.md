# 梦幻西游手游落地页（概念设计）

这是一个围绕《梦幻西游》手游制作的非官方互动落地页概念作品，展示三界世界观、三族主角、门派技能、召唤灵、伙伴社交与下载入口。

## 在线预览

[打开 GitHub Pages 在线网站](https://zhujy9413-commits.github.io/dream-westward-journey-mobile-landing-page/)

## 功能

- 四张首屏 CG 轮播，支持按钮、圆点和滑动切换
- 世界观章节交互
- 人、仙、魔三族主角切换与角色大图展示
- 角色可选门派及门派图标
- 十四门派与代表技能筛选
- 技能图标悬浮／键盘聚焦名称提示
- 按携带等级分类的召唤灵图鉴
- 伙伴与社交玩法展示
- iOS、Android 官方下载入口
- 桌面端与移动端响应式布局

## 使用方式

项目是纯静态页面，无需安装依赖。直接打开 `index.html`，或使用任意静态文件服务器预览。
